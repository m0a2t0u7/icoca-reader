# ICOCAリーダー

スマホの背面にICOCAをかざして残高を読むAndroidアプリです。Suica・PASMOなど、同じ交通系ICでも残高と直近の利用履歴を読めます。

## できること

- かざすだけで残高を表示し、読み取り履歴を端末内に自動保存
- カード内の利用履歴の日付・種別・その時点の残高を表示
- Drive連携：最初に1回だけ保存先ファイルを指定すると、読み取るたびに同じファイルへ自動で書き直します
- 記録ファイルの共有
- 初回起動はライトモード、ダーク切り替えは端末内に保存、画面下部にバージョン表示

## Drive経由でSpace「残高｜ICOCA記録」へ取り込む流れ

1. アプリの「Drive連携ファイルを設定」で、Google Drive上のフォルダに icoca_records.json を作ります
2. 以後は読み取るたびに、そのファイルが最新の全履歴で書き直されます
3. MuseがDrive上のそのファイルを読み、新しい読み取りだけをSpaceへ追加します

取り込みは、声をかけたときか、定期チェックを設定したときに行います。

## 読み取り方式

- AndroidのNFC-Fで接続し、Read Without Encryptionを実行します
- 残高：サービスコード 008B のブロック0、11〜12バイト目
- 利用履歴：サービスコード 090F のブロック0〜9、残高は各ブロック10〜11バイト目、日付は4〜5バイト目

## 注意

- 実機での読み取り確認は、インストール後に行います
- APKはデバッグ署名です。個人利用の範囲で使います
